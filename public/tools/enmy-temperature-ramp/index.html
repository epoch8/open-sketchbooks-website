In plain words: how much the color rich on the way from light to shadow. Dip — in the halftone the color dims toward gray (dusty, airy, like distance). Flat — holds richness all the way (clean, bright, poster-like). Glow — flares brightest at the break of light and shadow (a rich glowing edge, like on an apple or a cheek). This is separate from the route: the route = where the hue goes, profile = whether it is dense or washed out.

3 Form — how we model

Lightness (tone)1.0
Warm-cool (modulation)0
Chroma (spread)1.0
body (halftone) = exact object color, we model the form around it (e.g. lime foliage is built through G3, not Y6)
Three ways to model the same form — three channels along the light→shadow arc. Lightness — classic modeling: highlight lighter, core darker, the tone carries the form. Warm-cool — Cézanne modulation: light goes warm, shadow goes cool at similar lightness, the form reads by temperature. Chroma — richness spread: >1 light richer, shadow toward gray; <1 the other way. Drop lightness to zero, add warmth — the form holds on one temperature, with no tonal ladder.

4 Character and strength

Key (lightness)0

Fill (second light) — second dot on the wheel (drag): angle = its hue, radius = saturation. Floods the whole object toward this color: at the wheel edge — a rich color bath (neon, water, fire, color grade), at the center — a pale airy haze. Strength = how much is flooded. By default the dot sits in the light complement (daytime sky); pull toward the light — blue-in-blue monochrome. In v3 it becomes a per-object dose = in planes.

Each gap between neighboring zones is its own ladder. Rows (straight / 2 / 3 / 4) set granularity: how many in-between colors sit between zones (formerly ramp detail, now one axis with hops).
